# Security Policy

## Supported Versions

Only the latest major version of `@independo/capacitor-emoji-picker` receives security fixes.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report it privately
via [GitHub Security Advisories](https://github.com/independo-gmbh/capacitor-emoji-picker/security/advisories/new)
or by emailing [developers@independo.app](mailto:developers@independo.app). Include a description of the issue, steps to
reproduce, and the affected version (s) if known.

We'll acknowledge your report as soon as possible and keep you updated as we investigate and fix the issue.
