## Emoji Picker Example

This app is used for manual validation of `@independo/capacitor-emoji-picker` across web, Android,
and iOS. Nothing in this folder is published to npm.

### Running this example

From the repository root:

```bash
pnpm install
pnpm -C example run start
```

To run on Android or iOS, sync and open the native project:

```bash
pnpm exec cap sync
pnpm exec cap open android
pnpm exec cap open ios
```
